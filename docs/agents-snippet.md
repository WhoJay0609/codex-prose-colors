# 建议的 Codex 回复样式片段

将以下内容复制到运行 Codex agent 的主机上的 `~/.codex/AGENTS.md`，按需合并已有规则。若 agent 在远程 Linux 主机上运行，这个文件也在 Linux 主机上；它只约定回复如何使用 Markdown。颜色由本机 Mac 上运行的 CSS 注入工具提供，两者分别配置。

```md
## Markdown 回复样式

根据内容语义使用 Markdown：标题用于分节，**加粗**用于关键结论和修改后的关键片段，*斜体*用于轻度强调，行内代码用于文件名、函数名和具体值，列表用于并列或分步内容，链接用于来源。

修改论文、rebuttal 或报告时，在解释修改时突出关键结论和新增或替换的措辞；未修改的上下文保持普通格式。提供可复制的正文、LaTeX、代码或保存文档时，内容保持干净，不加入仅用于聊天显示的强调标记。若展示修改前后，分开列出原文与修改稿，并明确指出改动；不要让颜色成为唯一的差异标记。

颜色由客户端样式决定。使用 Markdown 的语义格式，不要为了颜色改写内容或滥用标记。
```

该片段只建议 Codex 如何组织回复；它不安装或启动配色工具，也不保证其他客户端使用相同颜色。
